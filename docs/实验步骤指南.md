# 网络入侵检测系统（IDS）实验步骤指南

本文档详细介绍了如何执行网络入侵检测系统实验，包括环境搭建、流量捕获和特征提取等步骤。

## 实验环境需求

- 1台支持网络桥接的Linux服务器（作为交换机）
- 4台普通主机（可以是物理机或虚拟机）
- WireShark软件（所有主机）
- CICFlowMeter软件（用于特征提取）
- Kali Linux系统（攻击主机）

## 步骤一：单一网段实验环境

### 1.1 网络环境配置

1. 在服务器上执行以下命令配置单一网段环境：

```bash
cd IDS/scripts
sudo ./setup_network.sh single
```

2. 检查网络配置是否成功：

```bash
./setup_network.sh show
```

3. 配置每台主机的网络设置：
   - Host1: IP 192.168.1.101/24，网关 192.168.1.1
   - Host2: IP 192.168.1.102/24，网关 192.168.1.1
   - Host3: IP 192.168.1.103/24，网关 192.168.1.1
   - Host4: IP 192.168.1.104/24，网关 192.168.1.1

### 1.2 安装WireShark

在每台主机上安装WireShark：

- Windows系统：
  1. 下载WireShark安装包：https://www.wireshark.org/download.html
  2. 运行安装程序，按照向导完成安装
  3. 安装完成后，确保选择正确的网络接口进行捕获

- Linux系统：
  ```bash
  sudo apt-get update
  sudo apt-get install wireshark
  sudo usermod -a -G wireshark $USER
  ```
  注销后重新登录，确保权限生效

### 1.3 捕获正常流量

1. 在每台主机上运行以下命令开始捕获流量：

```bash
cd IDS/scripts
python3 capture_normal_traffic.py -i <网络接口名称>
```

2. 在网络中进行正常的网络活动，例如：
   - 浏览网页
   - 传输文件
   - 发送电子邮件
   - 视频会议
   - 其他日常网络活动

3. 确保每台主机都捕获了足够的流量数据（至少20万条）

### 1.4 特征提取

1. 安装CICFlowMeter：
   - 下载：https://github.com/ahlashkari/CICFlowMeter
   - 按照GitHub页面上的说明进行安装

2. 使用CICFlowMeter转换PCAP文件为特征文件：
   - 可以使用GUI界面操作
   - 或使用脚本中的convert_to_features函数

## 步骤二：双子网实验环境

### 2.1 网络环境重新配置

1. 清理单一网段环境：

```bash
cd IDS/scripts
sudo ./setup_network.sh clean
```

2. 配置双子网环境：

```bash
sudo ./setup_network.sh dual
```

3. 配置主机网络设置：
   - 子网A:
     - AttackerA: IP 192.168.10.101/24，网关 192.168.10.1
     - TargetA: IP 192.168.10.102/24，网关 192.168.10.1
   - 子网B:
     - AttackerB: IP 192.168.20.101/24，网关 192.168.20.1
     - TargetB: IP 192.168.20.102/24，网关 192.168.20.1

### 2.2 安装Kali Linux

在攻击机（AttackerA和AttackerB）上安装Kali Linux：

1. 下载Kali Linux ISO：https://www.kali.org/downloads/
2. 创建可启动USB或直接在虚拟机中安装
3. 按照安装向导完成安装
4. 安装完成后，更新系统：
   ```bash
   sudo apt update
   sudo apt upgrade
   ```

### 2.3 发起网络攻击

1. 在攻击机上运行攻击工具：

```bash
cd IDS/tools
python3 attack_tools.py -t <目标IP> -a <攻击类型> -d <持续时间>
```

2. 可选的攻击类型：
   - ping: Ping洪水攻击
   - syn: SYN洪水攻击
   - udp: UDP洪水攻击
   - slowloris: Slowloris慢速连接攻击
   - scan: 端口扫描
   - brute: 暴力破解攻击

3. 示例：
   ```bash
   # 对目标机器发起SYN洪水攻击，持续60秒
   python3 attack_tools.py -t 192.168.10.102 -a syn -d 60
   
   # 对目标机器发起端口扫描
   python3 attack_tools.py -t 192.168.10.102 -a scan
   ```

### 2.4 捕获攻击流量

1. 在靶机上运行以下命令捕获攻击流量：

```bash
cd IDS/scripts
python3 capture_attack_traffic.py -i <网络接口名称> -t <攻击类型>
```

2. 确保捕获了足够的攻击流量数据（至少10万条）

### 2.5 攻击流量特征提取

使用与步骤1.4相同的方法，利用CICFlowMeter将攻击流量PCAP文件转换为特征文件。

## 数据处理

收集的数据将存储在以下目录：
- 正常流量数据：IDS/data/normal/
- 攻击流量数据：IDS/data/attack/

所有PCAP文件和特征文件都将保存在这些目录中，便于后续分析和处理。

## 故障排除

1. 如果网络配置失败，检查网络接口名称是否正确
2. 如果WireShark无法捕获流量，检查用户权限
3. 如果CICFlowMeter转换失败，检查PCAP文件是否有效
4. 如果攻击工具无法运行，检查所需依赖是否安装
