# 网络入侵检测系统(IDS)实验环境

## 实验环境配置

### 步骤一：单一网段实验环境
- 1台交换机
- 4台主机（同属一个网段）
- 每台主机安装WireShark进行正常流量抓取
- 抓取20万条流量数据，形成.pcap文件
- 使用CICFlowMeters软件进行离线特征转化

### 步骤二：双子网实验环境
- 将4台主机分为两个子网，每个子网包含2台主机
- 每个子网中指定1台为攻击机，1台为靶机
- 攻击机安装KaliLinux系统
- 利用Kali中的工具对靶机发起不同类型攻击
- 使用WireShark抓取攻击流量（约10万条）
- 使用CICFlowMeters软件进行离线特征转化

## 目录结构
```
IDS/
├── configs/           # 网络配置文件
├── scripts/           # 自动化脚本
├── data/              # 流量数据
│   ├── normal/        # 正常流量数据
│   └── attack/        # 攻击流量数据
├── docs/              # 文档
└── tools/             # 工具脚本
```

## 使用的工具
- WireShark: 流量抓取
- CICFlowMeters: 特征提取
- KaliLinux: 网络攻击工具集
